# 🃏 Blackjack en Kotlin

Un juego clásico de Blackjack (21) desarrollado completamente en Kotlin. Este proyecto sirve como una excelente demostración de los fundamentos del lenguaje, el diseño orientado a objetos (POO) y la gestión del estado en aplicaciones.

## ✨ Características

* **Jugabilidad Clásica:** Reglas estándar del Blackjack (pedir carta, plantarse, victoria con 21, etc.).
* **Croupier Automatizado:** Lógica de la casa implementada (el croupier pide cartas hasta llegar a un mínimo de 17).
* **Gestión de Barajas:** Sistema de cartas dinámico que baraja y reparte de forma aleatoria sin repetir cartas.
* **Arquitectura Limpia:** Separación clara entre la lógica del juego, las entidades (Carta, Baraja, Jugador) y la interfaz.

## 🛠️ Tecnologías utilizadas

* **Lenguaje:** [Kotlin](https://kotlinlang.org/)
* **Entorno de desarrollo (IDE):** IntelliJ IDEA / Android Studio
* **JDK:** Java Development Kit 11+ (o versión correspondiente)
